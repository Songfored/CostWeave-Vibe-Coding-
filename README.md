# CostWeave

**本地优先、约束驱动、成本感知的多模型 Agent 决策与编排原型。**

CostWeave v0.2 不再只是根据几个关键词把任务发给固定角色。它先建立任务画像，显式估计难度、歧义、不确定性、时效性、风险、工具、模态和 Token 规模；随后用主流模型目录执行硬约束过滤、成功率预测、最低可行成本求解和预算内质量升级，最后生成可并行执行、逐节点验收、可追溯重规划的 DAG。

> v0.2 仍不会调用真实模型 API。模型目录和路由选择是真实决策逻辑，执行结果仍由离线模拟器生成。这样可以零配置演示控制面，同时避免误导用户认为已经完成真实通用智能体。

## v0.2 的关键提升

- 9 类任务识别：编码、研究、数据、数学、写作、策略、翻译、视觉与安全
- 10 级难度与任务画像：歧义、不确定性、风险等级、时效性、工具和模态需求
- 主动规划升级：难度过高或本地判断置信度不足时增加高级规划复核节点
- 约束优先路由：先检查上下文、最大输出、模态、工具、最低能力和质量门槛
- 多目标组合优化：先求全任务最低可行成本，再把剩余预算投入质量收益最大的模型升级
- 真实价格估算：按官方每百万输入/输出 Token 价格与节点 Token 估计计算美元成本
- 候选可解释性：每个节点保留前三名模型、预测成功率、成本、延迟和选择理由
- 科学分工：专业分支并行，且每个分支都有独立验证节点，不允许未经验证直接汇总
- 高风险复核：法律、医疗、金融、安全、隐私等信号自动增加独立安全审查
- 证据驱动重规划：适配器异常或验收失败时保留有效成果，重新计算剩余任务的预算组合
- 安全边界修复：请求 Schema、跨域、路径穿越、未知 API 与公开监听均有明确防护

## 快速运行

需要 Python 3.11 或更高版本，不需要第三方依赖。

```bash
python -m costweave.server
```

打开 `http://127.0.0.1:8765`。

命令行入口也可通过安装项目获得：

```bash
python -m pip install -e .
costweave
```

## 决策流程

```text
用户目标
  ↓
本地任务画像：类型 / 难度 / 歧义 / 风险 / 时效 / 工具 / 模态
  ↓ 低置信或高难度时主动升级规划
结构化任务合同与并行 DAG
  ↓
模型硬约束过滤
  ↓
成功率、成本、延迟、可靠性联合预测
  ↓
最低可行成本组合 → 预算内质量升级
  ↓
并行专业执行 → 每分支独立验收 → 冲突审查 → 最终汇总
  ↓ 失败证据
影响范围分析 → 保留有效成果 → 剩余预算重新路由 → 恢复执行
```

## 模型目录

目录快照日期为 **2026-07-17**，覆盖 OpenAI、Anthropic、Google、DeepSeek、xAI、Mistral、Alibaba 以及本地执行器。价格、上下文和工具支持来自厂商官方资料；能力向量与可靠性是 CostWeave 用于演示路由的启发式估计，不是厂商公布的基准分数。

详细型号、价格与来源见 [`docs/MODEL_CATALOG.md`](docs/MODEL_CATALOG.md)。页面中的“主流模型决策目录”也可直接浏览完整快照。

## 项目结构

```text
costweave/
├── domain.py          # 任务合同、任务画像承载字段、状态与计划
├── model_catalog.py   # 带来源与核验日期的模型事实快照
├── planner.py         # 多维任务分析、科学拆分、验收与升级节点
├── router.py          # 硬约束、多目标预测、预算组合优化
├── validator.py       # DAG、合同和结果的分层验收
├── executor.py        # 离线结构化执行模拟器
├── engine.py          # 并行调度、预算预留、异常恢复与重规划
├── server.py          # 本地 HTTP API 与静态页面
└── web/               # 决策可解释性控制台
```

## HTTP API

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/health` | 运行模式与版本 |
| `GET` | `/api/catalog` | 模型事实、能力向量、价格和来源 |
| `POST` | `/api/runs` | 创建任务画像、计划、路由和模拟运行 |
| `GET` | `/api/runs` | 最近运行 |
| `GET` | `/api/runs/{id}` | 计划、候选模型、事件、成本与成果 |

创建运行：

```json
{
  "goal": "搜索最新市场资料，开发数据分析应用并形成风险报告",
  "mode": "balanced",
  "budget": 2.0,
  "quality_floor": 0.82,
  "max_concurrency": 4,
  "simulate_replan": false
}
```

## 当前边界

- 不调用真实模型，因此只能证明编排决策和运行闭环，不能证明最终领域答案质量。
- 能力分数是需要通过真实评测持续校准的先验值。
- 厂商价格会变化；生产实现应定期刷新目录并保留版本快照。
- 本地模型的 API 价格记为零，但 GPU、电力、内存和运维成本尚未折算。
- Qwen 的官方价格以人民币计价；未配置汇率前仅展示，不参与美元预算组合。
- 当前只允许绑定回环地址，不应直接暴露到公网。
