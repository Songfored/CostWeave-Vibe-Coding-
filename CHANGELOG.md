# Changelog

All notable changes are documented here. Historical detail remains in the
version-specific files under `docs/`; the Git tags are the canonical source
snapshots.

## Unreleased

- Refresh the editable model catalog with a 2026-08-27 source-backed market
  snapshot and separate official facts from independent and vendor-reported
  benchmark evidence.

  reporting guidance.

## v0.6.9 — 2026-08-27

- Add the Authoritative Decision Bridge, which records five advisory decision
  modules in a single immutable Run envelope without granting execution power.
- Keep external provider calls disabled by default. See
  [`docs/CHANGELOG-v0.6.9.md`](docs/CHANGELOG-v0.6.9.md).

## v0.6.8 — 2026-08-26

- Consolidate delivery and UX behavior, version identity and clean packaging.

## v0.6.7 — 2026-08-22

- Establish unified local request and external-call security boundaries.

## v0.6.0–v0.6.6 — 2026-08-09 to 2026-08-21

- Build the decision-intelligence lab, capability evidence graph, joint search,
  recovery, safe learning, gateway/runtime foundations and small-budget shadow
  boundary. Individual release notes remain under `docs/`.

## v0.5.1–v0.5.8.4 — 2026-07-28 to 2026-08-09

- Evolve the planner, MultiPlanner, outcome governance, calibration, evaluation

## v0.4.1–v0.4.9 — 2026-07-19 to 2026-07-28
