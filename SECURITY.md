# Security policy

CostWeave is currently a local-first research prototype. It is not declared
production-ready and must not be exposed directly to the public internet.

## Reporting a vulnerability

Do not include secrets, private prompts, access tokens, or a working exploit in
a public issue. Use GitHub's private vulnerability-reporting flow for this
repository when it is available. If it is unavailable, open a minimal issue
containing only the affected version, impact summary, and a request for a
private contact channel.

Reports should include reproducible steps, affected files or endpoints, impact,
and any safe mitigation already identified. Maintainers will acknowledge a
report before discussing remediation details publicly.

## Scope and supported line

The supported development line is the latest tagged release on `main`. Historical
tags are retained for reproducibility and are not retroactively supported.
