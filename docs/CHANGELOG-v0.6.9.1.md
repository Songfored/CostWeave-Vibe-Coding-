# CostWeave v0.6.9.1 变更说明

## 定位

`v0.6.9.1` 是在 v0.6.9 之上的真实实验稳定化半成品冻结版，不是生产版本，也不宣称已经证明 CostWeave 的质量或商业降本优势。冻结目的是保留当前已修正状态，避免下一轮实验继续在未记录的工作树上叠加修改。

## 冻结内容

- v11-ready Aurora 三策略真实实验入口；
- 确定性节点本地优先，失败后才进入模型路由；
- 动态预算预留、并行超时隔离和关键节点单次替补；
- 密钥检查误报修复与同项目并发适配器修复；
- 失败、拒收、替补和传输异常的成本泄漏归因；
- Claude、GPT 中转站人民币计费校准；
- DeepSeek 峰谷时段、缓存和人民币账单校准；
- 平台账单覆盖本地估算并保留残差的对账合同。
- v11 首轮真实质量实验后的四项定点修复：字典型提供商 ID 安全归一化、最小可行提供商集合确定性求解、媒体 JSON 模式/有限修复/受预算替补，以及实验账本正常完成态。

## 已知边界

- v11 首轮真实实验已完成，但三种策略均未通过最终 Oracle；本快照只修复已定位根因，不把旧结果改写为成功；
- 后续真实重复实验仍须使用新的实验 ID、运行 ID、数据库和新的明确授权；
- 当前内部原子预算账本仍保存保守参考美元，人民币实扣使用独立校准层展示；
- 平台账单到达前只能称预计人民币成本；
- 修复效果目前只有离线回归证据，尚未获得第二轮真实调用证据；
- `production_ready=false`。
