# CostWeave v0.6.9 安全边界

v0.6.9 没有扩大网络、身份、审批、秘密或真实 Provider 权限。v0.6.7 的统一安全边界继续适用。

新增决策桥的安全属性：

- 只在正式路由确定后读取运行快照；
- Adapter 回执必须声明零 Provider、网络和外部调用，否则视为无效并失败关闭；
- Envelope 记录的效果计数固定为正式路线、预算、任务状态和 DAG 影响 0；
- 模块异常不会传播为 baseline 执行失败；
- API 复用既有项目/驻留域可见性检查，仅提供只读结果；
- 不接收新的秘密，不开放远端 endpoint，不执行策略晋级。

本版没有重新执行 v0.6 系列完整深度安全验收；完整详验按用户要求留到后续单独进行。`production_ready=false`。
