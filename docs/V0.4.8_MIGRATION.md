# CostWeave v0.4.8 迁移指南

v0.4.8 在 v0.4.7 数据库上追加迁移 007，不删除或重写既有运行、事件、Artifact、Placement、验收、恢复、预测或 Outcome 记录。

## 升级

1. 停止旧进程并备份 `~/.costweave/runtime-v4.sqlite3`。
2. 安装或解压 v0.4.8。
3. 启动服务；迁移自动创建媒体项目、圣经、镜头合同、Prompt、渲染尝试、连续性检查和媒体成本表。
4. 访问 `/api/health`，确认：
   - `version` 为 `0.4.8`
   - `control_kernel.runtime_schema` 为 `v4.8`
   - `control_kernel.migrations` 为 `7`
   - `features.media_workflow` 为 `true`

旧 v4.2～v4.7 投影继续兼容读取。旧运行不会被反向补造媒体项目；新运行只有在媒体意图识别通过后才创建媒体记录。

## 回滚媒体写入

```powershell
$env:COSTWEAVE_MEDIA_WORKFLOW="0"
python -m costweave.server
```

关闭后通用规划、路由、执行、验收、恢复和结果预测继续工作；不为新运行创建媒体项目。既有媒体表和记录保持可读，不做破坏性降级。

## 数据解释

- `media_projects` 保存媒体需求画像、制作策略和项目快照。
- `media_bible_revisions` 保存 Creative Brief、Film/Character/Location Bible 与素材登记。
- `shot_contracts` 保存不可静默改写的镜头边界与批准状态。
- `prompt_revisions` 保存目标适配器、继承引用、锁定意图哈希与语义差异。
- `media_render_attempts` 只保存仿真元数据，不包含真实媒体。
- `media_continuity_checks` 保存技术、身份、场景、动作和首尾帧验证。
- `media_cost_ledger` 保存每个生产阶段、镜头、尝试和有效秒的仿真成本。
