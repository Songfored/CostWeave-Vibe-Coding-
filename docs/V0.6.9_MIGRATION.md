# 升级到 CostWeave v0.6.9

v0.6.9 不新增数据库迁移。Runtime Schema 保持 `v6.5.0`，迁移数保持 35。

## 行为变化

- 新 Run 的快照增加 `decision_bridge`；
- 新增只读接口 `GET /api/v1/runs/{run_id}/decision-bridge`；
- `/api/health` 增加 `decision_bridge` 权限与零影响声明；
- 页面运行详情增加统一影子决策卡片；
- 当前应用版本与发布物变为 `0.6.9`。

旧投影缺少新字段时会按 `None` 载入，不影响恢复。新字段保存在现有 JSON 投影中，无需改表。
