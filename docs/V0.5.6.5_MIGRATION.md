# CostWeave v0.5.6.5 升级说明

v0.5.6.5 可直接覆盖 v0.5.6.4.4。首次启动自动应用 migration 021，将 Runtime Schema 从 `v5.6.4.4` 升级为 `v5.6.5`；既有运行、预测器、Portfolio 审计和精确验收记录保持不变。

## 新增数据表

- `policy_candidates`：冻结策略候选及其预测器、数据、Schema、目标、约束、范围和回滚绑定。
- `offline_bandit_evaluations`：共同支持、IPS/SNIPS/DR、有效样本、权重和证据门报告。
- `policy_freeze_assessments`：漂移、校准、任务族、成本、时延、质量和隐私冻结结果。
- `policy_cards`：优势、失败模式、覆盖、不支持范围、区间与回滚目标。
- `policy_candidate_deletions`：候选删除后的不可变哈希墓碑。

## 行为变化

- `/api/v1/predictors/policy` 的顶层 Schema 升级为 `v0.5.6.5`，旧的 admission 与 offline evaluation 内容仍作为嵌套字段返回。
- 默认安装不会创建策略候选、调用外部 Provider、执行探索、改变正式路线或晋级策略。
- 只有已持久化且通过的预测器离线评估可以创建策略候选。
- 删除候选必须提供受限原因码；候选负载和子记录级联删除，但保留不含原文的哈希墓碑。

## 兼容与回滚

- 正式路由继续由 `legacy-resource-optimizer` 掌握。
- v0.5.6.5 候选固定为 `advisory_only=true`、`routing_authority=false`、`may_change_actual_route=false`、`automatic_promotion_allowed=false`。
- 回退代码前请保留数据库备份；旧版本不会理解 migration 021 的新表，但既有表格式没有被改写。

## 证据边界

升级不会自动把历史 Outcome 转换成 Bandit 证据。E0 测试数据只验证公式和安全门，不能支撑真实收益、固定降本比例或商业声明。
