# CostWeave v0.5.7.4

## 新增

- Bounded Canary Runtime Plane：`5% → 25% → 50% → 100%` 顺序发布和逐阶段样本门；
- 显式部署授权：绑定签名候选、稳定回滚策略、注册表指针、Canary 门、批准、任务范围和内容哈希；
- 确定性运行分桶与 normal/low 风险白名单；elevated/high 风险和范围外任务固定回稳；
- 每个运行的不可变策略启动快照，进入权威投影并支持重启恢复；
- 成功率、严重错误、预算、权限、P95、漂移、校准、重复副作用、高风险探索和策略元数据自动回滚门；
- migration 025：不可变部署、运行时指针、任务分配、观察窗和阶段决定；
- `GET /api/v1/canary/policy` 及 Canary 响应式控制台。

## 安全与一致性

- Canary 默认关闭，必须显式设置 `COSTWEAVE_CANARY_ENABLED=1`；
- 部署不授予 Provider 凭据、不扩大工具权限，也不自动启用真实 Adapter；
- 存储层重新计算确定性分桶和门决定，拒绝伪造候选队列、跳级或压制回滚；
- 回滚不改写进行中任务，新任务立即获得稳定策略快照；
- 所有阶段决定和指针事件的执行副作用计数为 0。

## 验证

- 657 项自动化测试通过；
- v0.5.7.4 新增 12 项专项合同/存储/恢复测试和 1 项公开 API 测试；
- 桌面、平板和手机浏览器检查均无横向溢出或应用控制台错误；
- 完整历史套件继续覆盖并发调度、审批、Artifact DAG、恢复、预测、策略注册表、Shadow 和回放。

## 证据边界

本版没有产生真实 Provider Canary 流量。候选策略选择计数只表示运行时策略版本进入任务快照，不等于外部模型已经调用，也不能用于宣传真实降本、成功率或时延改善。
