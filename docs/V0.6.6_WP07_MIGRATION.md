# V066-WP07 migration guide

No SQLite migration or runtime schema bump is required. WP07 is additive and
reuses the experimental-call tables introduced by migration 016. Existing
runtime, gateway and run APIs remain compatible.

To integrate a Provider, implement `ShadowProbeExecutor` outside the control
kernel, construct one shared `SmallBudgetShadowRuntime` over the existing
`ExperimentalCallStore`, and inject it into `build_server`. Keep Provider
transport, credential resolution and billing parsing inside the adapter. Do
not bypass `probe()`, because it owns admission, project scope, idempotency and
the atomic pre-call budget reservation.

After restart, submit the same configuration again to re-arm it. The durable
ledger recognizes the original fingerprint and budget, while process-local
consent is deliberately not restored. Reusing the key with different content
fails closed.

Rollback is a code/configuration rollback: leave the experimental-call switches
off and stop using `/api/v1/runtime/shadow/*`. Existing ledger rows are
append-only evidence and need not be deleted.
