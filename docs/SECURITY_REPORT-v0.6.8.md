# CostWeave v0.6.8 安全边界

v0.6.8 没有扩大网络、身份、审批、秘密或真实 Provider 权限。v0.6.7 修复后标准扫描 `6897135e-a85a-4c65-9088-d62a3ae6f573` 的 12/12 威胁面、0 项可报告发现结论继续作为安全基线。

本版新增的交付安全措施包括：

- 发布文件白名单，不遍历复制仓库根目录生成物；
- 拒绝归档中的路径逃逸、绝对路径、工作目录、输出目录、数据库、日志、密钥、环境文件和缓存；
- 清理 staging 前验证构建器标记，避免误删未标记目录；
- 动态页面只替换固定版本占位符，不接受用户输入模板；
- 不修改外部调用安全合同 Schema，不弱化 v0.6.7 的安全门禁。

本报告不是公网、多租户、供应链或生产安全认证。完整 v0.6 结束后再进行统一详细验收；本版只做一次简短版本验收。
