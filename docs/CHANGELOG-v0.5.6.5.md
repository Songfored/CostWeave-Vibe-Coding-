# CostWeave v0.5.6.5

发布日期：2026-08-04  
主题：Safe Policy Candidate & Offline Counterfactual Gate

## 新增

- 不可变 `PolicyCandidate` 和策略范围、数据时间窗、报告版本及回滚绑定。
- 低风险探索上限与高风险、不可逆、权限敏感探索禁区。
- 完整日志/候选动作概率合同和共同支持检查。
- IPS、SNIPS、Doubly Robust、反事实差值、区间、有效样本量和最大重要性权重诊断。
- PSI、ECE、任务族成功率、成本/时延 P95、数据质量和隐私冻结门。
- 可审查策略卡、完整导出和带不可变墓碑的安全删除。
- migration 021、Runtime Schema `v5.6.5` 与公开策略 API。

## 安全边界

- 默认外部调用：0。
- 默认探索执行：0。
- 策略实际路由干预：0。
- 自动生产晋级：0。
- 测试夹具商业声明资格：关闭。
- 正式回滚目标：既有规则策略。

## 验证

- 新增 25 项专项测试。
- 自动化测试基线：572 项。
- E0 已知值夹具验证候选策略值 `0.7`、日志策略值 `0.6` 和 DR 差值 `0.1`；这些数字只验证计算实现，不是现实收益。

- 任何可对外宣传的真实降本、提速或成功率改善结论。
