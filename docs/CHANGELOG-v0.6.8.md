# CostWeave v0.6.8 发布说明

版本主题：Delivery & UX Convergence（交付与体验收口）  
证据等级：E0 本地工程验证  
生产就绪：`false`

## 本版完成内容

- 新增 `costweave/version.py`，网页、HTTP 服务、健康接口、CLI、Python 包元数据和发布清单统一读取当前版本；
- 健康接口只返回一个当前版本，历史稳定基线仅作为有明确字段名的背景信息保留；
- 顶部导航在桌面端自然换行，在小于 768px 时变为完整折叠菜单，支持键盘、Escape 关闭和焦点恢复；
- 页面明确展示 v0.6 WP01—WP07 已完成，不再用超长单行版本串挤压导航；
- 扩充 `.gitignore`，排除工作区、输出、日志、运行数据库、缓存和本地代理元数据；
- 新增白名单发布构建器，只从干净 staging 生成 wheel、sdist、源码 zip、发布清单和 SHA256；
- 归档检查拒绝 `work/`、`outputs/`、旧数据库、日志、密钥、环境文件、缓存和历史构建目录；
- 记录当前无效 `.git` 元数据的非破坏性恢复方案，没有擅自覆盖用户仓库历史。

## 明确未改变

- Runtime Schema 仍为 `v6.5.0`，数据库迁移仍为 35 项；
- v0.6.0—v0.6.5 智能模块仍是 advisory-only，尚未共同接管一次正式 Run；
- 外部模型、真实付费调用与策略自动晋升仍默认关闭；
- v0.6.7 的外部调用安全合同 Schema 保持原值，不因应用展示版本变化而伪造协议升级；
- 不宣称真实降本比例、生产并发能力或商业领先。
