# CostWeave v0.6.7 实施规格

## 目标

在不启用真实 Provider、不修改智能路由算法的前提下，修复既有标准扫描确认的 11 条攻击路径，并建立两项可复用边界：`RequestSecurityContextV1` 与 `ExternalCallAuthorityV1`。

## 组件

1. `security_boundary.py`：请求上下文、风险 Prompt 准入、秘密租约与公开安全策略；
2. `approvals.py`：审批身份唯一性和精确绑定查询；
3. `external_call_authority.py`：外呼准入、预留、一次性 capability、输出检查和关闭；
4. `adapters/http.py`：固定 peer 的 HTTPS transport、全局 replay、模糊成本与秘密检查；
5. `server.py`：统一入口认证、项目状态、静态路径和并发上限；
6. `engine.py`：驻留域过滤；
7. `web/app.js`：本地会话令牌传播；
8. `release_readiness.py`：安全基础自检门禁；
9. `tests/test_security_recovery_v067.py`：原攻击路径回归。

## 不变量

- 未经权威准入不得到达 transport；
- capability 一次性且与最终请求绑定；
- 活跃秘密不得进入耐久状态；
- 模糊账单不能释放全部预算；
- 全局副作用不得跨实验重复；
- 项目撤销、驻留域、身份和 Host 在资源访问前生效；
- 过载必须有界且可恢复。

## 兼容边界

本版保留既有数据库迁移 035 和运行时 Schema v6.5，不新增持久化迁移。内部裸 Store API 尚未全部改成只接受安全上下文；HTTP 权威入口和关键资源读取先完成迁移，剩余结构收口放在后续受控版本。

## 验收

必须同时通过专项攻击回归、全量测试、隔离测试、发布门禁、干净安装和独立标准安全复扫。前五项已经通过，复扫因历史构建归档读取错误尚未完成，所以规格的最终关闭条件仍未满足。
