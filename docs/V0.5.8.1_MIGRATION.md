# CostWeave v0.5.8.1 升级说明

v0.5.8.1 可直接覆盖 v0.5.7.4。首次启动自动应用 migration 026，将 Runtime Schema 从 `v5.7.4` 升级为 `v5.8.1`；Run Projection Schema 继续为 `v5.6`。既有运行、Artifact、Outcome、回放、Shadow、策略、注册表和 Canary 记录保持不变。

## 默认行为

- 不启用任何真实 Provider；
- 不产生付费调用；
- 证据控制台默认显示工作区级证据，可切换到具体运行；
- 没有真实独立验收、账单对账或足量端到端样本时，真实成功率、CPS 和 P95 显示为缺失；
- 商业结论门默认失败关闭。

## 数据库变化

migration 026 新增：

- `evidence_export_receipts`
- `trg_evidence_export_receipts_no_update`
- `trg_evidence_export_receipts_no_delete`

收据保存导出 ID、包哈希、范围、运行 ID、记录计数和生成时间。同一规范化包哈希幂等复用既有收据；数据库触发器拒绝原地修改和删除。

## API 变化

- `GET /api/v1/evidence/console`：工作区证据；
- `GET /api/v1/evidence/console?run_id={id}`：单运行证据；
- `GET /api/v1/evidence/exports?limit={n}`：不可变收据；
- `POST /api/v1/evidence/exports`：生成实验包并保存收据，请求体可为 `{}` 或 `{"run_id":"..."}`。

导出包最多包含 20 个运行和 1,000 个事件，不包含密钥、Prompt 原文、Artifact 内容或原始用户标识。调用方应同时保存 JSON 文件与返回的 SHA-256。

## 回滚到旧程序

代码可回退到 v0.5.7.4；旧程序会忽略 migration 026 和证据导出收据，但不会删除它们。回退前应停止当前进程并备份 SQLite。用旧程序运行期间无法创建或验证新的统一实验包收据。
