# v0.6.6 migration and rollback

## Upgrade

1. Install the v0.6.6 wheel or source archive in a fresh Python 3.11+
   environment.
2. Keep the existing runtime database. No migration is required; the runtime
   remains schema v6.5.0 with migration 035.
3. Import gateway contracts from `costweave.gateway_backend` or
   `costweave.adapters`.
4. Run the focused contract tests and the release status command before
   enabling any future adapter work.

Example:

```python
from costweave.adapters import GatewayMessageV1, GatewayRequestV1

request = GatewayRequestV1.create(
    trace_id="trace-066", project_id="local-default", model="example-model",
    messages=(GatewayMessageV1(role="user", content="hello"),),
    max_output_tokens=128, idempotency_key="idem-066",
)
```

## Rollback

Stop using the v0.6.6 contract imports and reinstall v0.6.5. Because no
database migration or network setting was changed, rollback does not require a
database restore. Do not feed v0.6.6 serialized objects to a v0.6.5 consumer;
the schema version check is intentionally strict.

## Boundary

This release does not enable external calls. Any later adapter rollout needs a
separate work package, explicit configuration, bounded budgets and new
acceptance evidence.
