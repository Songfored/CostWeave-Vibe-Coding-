# CostWeave v0.5.7.2 升级说明

v0.5.7.2 可直接覆盖 v0.5.7.1。首次启动自动应用 migration 023，将 Runtime Schema 从 `v5.7.1` 升级为 `v5.7.2`；旧运行、回放、预测器、Portfolio 和策略候选记录保持不变。

## 新增数据表

- `production_shadow_inputs`：与基线对齐的匿名任务特征、目录、容量、实际路线和端到端估计。
- `production_shadow_decisions`：旁路建议、缺失原因、开销及零副作用字段。
- `production_shadow_failures`：不含异常正文、保证基线继续执行的隔离失败回执。
- `production_shadow_outcomes`：实际基线路线的 Outcome 与证据来源。
- `production_shadow_comparisons`：基线预测误差、建议路线一致性和未知反事实。
- `production_shadow_audit_reports`：覆盖率、缺失原因、延迟、成本开销和证据门。

## 行为变化

- 新增 `GET /api/v1/shadow/policy`。
- 健康状态新增 `production_shadow` 合同与运行计数。
- 默认安装不运行真实 Shadow 外部模型，不改变实际路线，不创建执行副作用，也不晋级策略。
- 成本开销比使用基线端到端估计成本作分母；P95 原则门为 10%。

## 兼容与回滚

- v0.5.6.3 的旧 Shadow 决定与比较表保留，旧 API 行为不变。
- 正式路线继续由现有基线路由器掌握。
- 新表记录不可修改或删除；决定与失败在同一输入和策略版本上互斥。
- 回退代码前请保留数据库备份；旧程序会忽略 migration 023 新表。

## 证据边界

升级不会启动真实 Provider 或采集实时容量。至少 30 个 E2+ 真实、独立、完整比较案例通过后才允许评估方向性 Shadow 结果；当前测试夹具不能证明现实开销低于 10% 或策略效果改善。
