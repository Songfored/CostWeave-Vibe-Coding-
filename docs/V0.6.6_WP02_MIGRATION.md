# v0.6.6 V066-WP02 migration and rollback

## Upgrade

No database migration is required. Runtime schema remains v6.5.0 with 35
migrations. Import the new classes from `costweave.gateway_openai` or
`costweave.adapters`.

```python
from costweave.adapters import (
    OpenAICompatibleGatewayBackend,
    OpenAICompatibleGatewayConfig,
    OpenAICompatibleRuntimePolicy,
)

backend = OpenAICompatibleGatewayBackend(
    OpenAICompatibleGatewayConfig(
        backend_id="local-openai",
        endpoint="http://127.0.0.1:11434/v1/chat/completions",
    ),
    policy=OpenAICompatibleRuntimePolicy(network_enabled=True),
)
```

The explicit policy is required for every actual local endpoint call. The
default constructor remains disabled and is suitable for dry-run wiring.

## Rollback

Remove the WP02 imports and reinstall the previous v0.6.6 WP01 artifact. No
database restore or migration reversal is needed because WP02 adds no durable
tables or events.
