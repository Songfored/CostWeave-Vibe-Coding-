# CostWeave v0.5.6.4.3

## 新增

- `PortfolioProblem`、节点、依赖边和部署候选的不可变输入合同。
- 整张 DAG 的有界确定性 Beam Search；披露状态数、硬约束剪枝、Beam 剪枝、截断和是否证明最优。
- 完整损失目标：模型、验收、工具、交接、预期返工、升级、下游失效、失败相关性、时延与任务失败损失。
- 基于 DAG 的 P95 关键路径，不把可并行分支线性相加。
- Provider 共享配额、同拓扑层资源池容量、预算、截止时间、能力、驻留、节点/组合成功率硬门。
- 高风险 Validator 的模型和失败域独立约束。
- `fine_grained`、`consolidated` 与当前拓扑的同组场景比较。
- migration 019 的不可变、带哈希审计存储与数据库级零权威约束。
- `GET /api/v1/portfolio/policy` 和健康状态中的全局组合审计边界与计数。

## 硬边界

- 只做离线建议，不改变实际路线、Prompt、工具、预算或执行顺序。
- E0 规则先验不构成方向性真实证据；E2+ 也只能允许方向性比较，不能自动获得正式路由权。
- 有界搜索可能发生 Beam 剪枝，发生时不宣称已证明全局最优。
- 没有真实 Provider 调用、真实训练、Shadow 干预、策略晋级或商业效果声明。
