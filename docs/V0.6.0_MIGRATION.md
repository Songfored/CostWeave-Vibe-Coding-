# v0.6.0 migration notes

## Version relationship

- Stable baseline: `v0.5.8.4`.
- Active development line: `v0.6.0`.
- Existing migrations `001` through `029` are unchanged.
- Migration `030_decision_intelligence.sql` adds only the v0.6.0 decision-object and tournament-run tables.
