# v0.6.6 V066-WP05 migration and rollback

## Upgrade

No database migration is required. WP05 keeps runtime schema `v6.5.0`, 35
migrations and projection schema `v5.6`. New projections persist an optional
stable `trace_id`; old projections derive the same shape from their run ID at
load time.

Applications may use:

```python
from costweave.observability import TraceRecorder, public_observability_policy

recorder = TraceRecorder()
print(public_observability_policy())
```

The normal runtime creates and registers its own recorder. Pass only
allowlisted operational metadata. Do not pass prompt/provider payload contents,
headers, credentials or unrestricted exception text as attributes;
pattern-based redaction is defense in depth rather than a universal secret
detector. The trace endpoint is read-only and external export remains
disabled.

Recognized sensitive values are represented only by `redacted`, `kind`,
`value_type` and optional `length`; no source-value digest or preview is
retained. Non-finite values are rejected and exported values use strict JSON.

The global recorder lookup is a `WeakValueDictionary`, so it does not own
recorder lifetime. Applications that register their own recorder must retain a
strong reference for as long as provider-call spans are required.

The Trace ID and event-derived lifecycle spans can be reconstructed after a
restart. Provider-call spans remain process-local in WP05 and must not be
treated as durable audit records.

No database or projection migration is required. Use only the `fixed-final`
wheel/ZIP/checksum artifacts listed in
`INSTALL_REPRODUCE-v0.6.6-wp05.md`; both original and pre-final `fixed`
artifacts are superseded. The final artifacts are bound to the 995/995 ordinary
and isolated full runs and the 16/16 `fixed-final` wheel release-readiness
result.

## Rollback

Stop using `/api/v1/runs/<run_id>/trace` and remove the WP05 imports. No schema
rollback is needed. Existing run projections and EventStore events remain
compatible; the added trace ID field is ignored by older readers and can be
re-derived from the run ID.
