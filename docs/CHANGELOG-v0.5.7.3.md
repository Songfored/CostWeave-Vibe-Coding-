# CostWeave v0.5.7.3

## Added

- 新增带 HMAC-SHA256 内容签名的版本化 `PolicyManifest`；签名覆盖来源报告、代码、目标、约束、任务族、MultiPlanner 意图和回滚目标。
- 新增 `draft → evaluated → shadow → canary → active → frozen/retired` 受控状态机、连续修订与防跳级检查。
- 新增 evaluation、shadow、canary、activation 四级晋级证据门，固化真实来源、独立评测、样本量、质量非劣、CPS、并行 P95、Handoff 返工、校准、漂移、隐私和硬违规门槛。
- 新增 MultiPlanner 默认价值门：困难集成功率 `+5pp` 或 Routing Regret 改善 `15%`。
- 新增解释性策略卡，展示适用/禁止任务族、优势、失败模式、不支持范围、阻断原因、下一证据阶段和回滚目标。
- 新增一键冻结与原子注册表回滚收据；当前策略冻结和注册表指针重定向同事务写入。
- 新增 migration 024 七类不可变表与注册表指针事件日志。
- 新增 `GET /api/v1/policies/registry` 公开生命周期、门槛、边界和运行计数。
- 页面新增响应式策略生命周期、证据门、冻结/回滚与零真实路由变化面板。

## Safety

- 策略签名密钥不入库；长度不足、签名错误或内容被篡改均拒绝注册。
- 过期修订、顺序跳级、证据跨版本复用、未持久化门报告、缺少批准和错误回滚目标均失败关闭。
- 注册表 `active` 不等于生产激活；运行路线变化、运行时激活、运行时回滚和执行副作用仍固定为 0。
- 测试夹具只验证工程合同，不构成真实策略晋级或商业效果证据。
- 统一运行记录锁与内核写锁的获取顺序，消除并行分支写事件与审批解析之间的锁顺序反转。
