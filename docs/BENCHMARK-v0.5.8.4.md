# CostWeave v0.5.8.4 Benchmark 报告

日期：2026-08-09

## 结论先行

v0.5.8.4 达到离线、单进程控制平面的工程稳定门，但没有达到真实 Provider 或生产性能门。本报告中的自动化、故障、并发、预测和重放结果均属于 E0 本地验证；不得换算为固定降本比例或商业领先结论。

## 基准范围

| 基准 | 范围 | 证据 | 结论 |
|---|---|---|---|
| 完整自动化回归 | 全仓库独立进程 unittest | E0-local | 见验收报告中的最终计数 |
| 稳定版专项 | 迁移、全量重放、发布证明、API、全新安装 | E0-local | 12 项 |
| 固定任务集 | 35 个版本化种子任务 × 5 个基线 | E0-simulated | 只验证评测协议与矩阵完整性 |
| 故障转移 | Provider down / OOM 确定性夹具 | E0-simulated | 满足 30 秒工程合同 |
| deadline 预警 | 24 个合成案例 | E0-simulated | recall 1.0，AUROC 1.0 |
| 有界并发 | 64 个操作、并发 8 | E0-local | worker 泄漏 0 |
| 并发追加写 | 48 条韧性观测 | E0-local | 无丢失，幂等冲突拒绝 |
| EventLog 重放 | 每个持久运行与当前投影逐一比较 | E1-replayed | 全量、非抽样审计 |
| Wheel 全新安装 | 隔离目录安装、运行、重放、备份校验 | E0-local | 由 `costweave-release` 复现 |

## 可复现命令

```bash
python -B tests/run_isolated.py
costweave-release --pretty
```

发布 wheel 还必须在与源码目录隔离的目标目录安装后再次执行 `costweave-release --pretty`。成功输出需要同时满足：模拟运行完成、全部运行可重放、备份文件/逻辑快照匹配、外部调用尝试为 0。

## 未执行的基准

- 30～50 个方向性真实任务；
- 真实国内外 Provider 的质量、账单、限流和 P95；
- 生产规模长时间并发与分布式恢复；
- 与人工分流、全强模型、全低价模型在相同任务集上的 E2+ 对照；
- 统计显著的真实 CPS、成功率、返工率或时延改善。

因此，当前只可以声明“工程合同可复现”，不能声明“成本只有基线的某个固定比例”。
