# CostWeave v0.5.6.2 升级说明

v0.5.6.2 可直接覆盖 v0.5.6.1 程序并继续使用原数据库。首次启动会自动应用 migration 015，将 Runtime Schema 从 `v5.6.1` 升级到 `v5.6.2`；Run Projection Schema 保持 `v5.5`，旧任务投影无需重写。

## 数据库变化

新增四张表：

- `outcome_datasets`：不可变数据集清单、来源报告哈希、质量报告和冻结状态；
- `outcome_learning_samples`：匿名化学习副本、分区、去重组、权重、用途和 TTL；
- `outcome_label_events`：追加式标签证据；
- `outcome_deletion_audits`：删除后的样本哈希、标签集合哈希和原因码。

原始 `evaluation_runs` 与 `evaluation_observations` 仍是实验事实源。治理数据是可删除的学习副本，不会反向修改实验报告。

## 生成数据集

```powershell
$env:COSTWEAVE_DATASET_PRIVACY_SALT="<至少16字节的私密随机值>"
python -B -m costweave.outcome_dataset `
  outputs/CostWeave-v0.5.6.1-evaluation/experiment.json `
  --output-dir work/v0562-outcomes `
  --database work/v0562-runtime.sqlite3
```

同一报告、盐、用途、TTL 和创建时间可确定性重放。不同内容不能静默覆盖同名导出文件。

## 安全边界

- 不在命令行历史中复用生产隐私盐；正式环境应从秘密管理器注入。
- 学习副本不含原始目标、项目/用户/任务标识、参考答案、输出正文或原始证据引用。
- E0 模拟数据、有效样本不足、项目泄漏、治理失败或标签异常都会冻结训练。
- 本版没有真实 Provider 调用、模型训练、Shadow 干预或策略晋级。

## 回退

回退前先备份数据库。v0.5.6.1 不认识 migration 015，建议保留 v0.5.6.2 程序读取升级后的数据库；若必须运行旧程序，应恢复升级前备份，不要手工删除迁移记录或治理表。
