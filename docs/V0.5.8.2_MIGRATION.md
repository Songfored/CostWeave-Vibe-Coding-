# CostWeave v0.5.8.2 升级说明

v0.5.8.2 可直接覆盖 v0.5.8.1。首次启动自动应用 migration 027，将 Runtime Schema 从 `v5.8.1` 升级为 `v5.8.2`；Run Projection Schema 继续为 `v5.6`。

## 数据迁移

- 既有 Run 自动按 `project_id=local-default`、`data_residency=local` 恢复。
- 既有 evidence export receipt 自动增加 `project_id=local-default`。
- 新增项目逻辑撤销墓碑、外部副作用合同和副作用事件表；均由触发器禁止更新和删除。
- migration 不会删除或重写既有运行、Artifact、Outcome、策略、Canary 或证据记录。

## 项目隔离

不设置请求头时行为与旧版一致，所有运行属于 `local-default`。需要隔离时，对运行和证据相关请求稳定发送：

```text
X-CostWeave-Project: project-alpha
X-CostWeave-Data-Residency: local
```

项目头只是本机控制面的范围选择，不是公网身份认证。服务仍只能绑定 `127.0.0.1`、`localhost` 或 `::1`。

撤销项目需要：

```text
POST /api/v1/projects/project-alpha/revoke
X-CostWeave-Project: project-alpha
Idempotency-Key: revoke-project-alpha-001
Content-Type: application/json

{"confirm":"REVOKE project-alpha"}
```

撤销会立即隐藏该项目并禁止新任务，但不会物理删除历史 SQLite 行；响应始终如实标明 `physical_rows_deleted=false`。

## Adapter 与密钥

- `COSTWEAVE_EXPERIMENTAL_ADAPTERS=1` 仍是第一开关；远程或付费部署还需要 `COSTWEAVE_PAID_CALLS=1`。
- 只有内置版本锁定插件可运行；远程端点必须是公网 HTTPS，且不能包含凭据、查询或片段。
- Adapter 配置只能引用环境变量名，不能携带密钥值。密钥缺失、太短、过长或插件无密钥能力都会在网络前拒绝。
- Provider 请求会收到稳定 `Idempotency-Key`；连接结果不明时不会自动重试。

## 回滚

若需要回滚代码，可恢复 v0.5.8.1 文件；migration 027 表和列应保留，不要手工删除。旧代码会忽略新增安全记录。已经撤销的项目若在旧代码中运行，将失去 v0.5.8.2 的逻辑访问保护，因此不建议在存在撤销墓碑时回滚。

## 验证

```bash
python -B tests/run_isolated.py
```

预期结果：679 项测试、0 失败；`GET /api/health` 返回版本 `0.5.8.2`、Runtime Schema `v5.8.2` 和 27 项 migration；`GET /api/v1/security/policy` 显示外部网络默认关闭、密钥值不持久化和当前项目状态。
