# CostWeave v0.5.6.4.2 升级说明

v0.5.6.4.2 可直接覆盖 v0.5.6.4.1。首次启动自动应用 migration 018，将 Runtime Schema 从 `v5.6.4.1` 升级为 `v5.6.4.2`，既有 Run Projection 继续兼容 `v5.5`。

新增表：

- `predictor_candidate_artifacts`
- `predictor_evaluation_reports`
- `predictor_challenger_comparisons`

这些表只接受已通过上游准入的不可变版本引用，并固定正式路由权与策略晋级权为 false。升级不会自动训练模型、导入测试夹具、创建 Shadow 候选或调用外部 Provider。

升级后访问 `GET /api/v1/predictors/policy`，默认应看到：

- `schema_version: v0.5.6.4.2`
- `current_state: frozen_no_real_evidence`
- `policy_promotion_enabled: false`
- `routing_authority: legacy-resource-optimizer`
- `predictor_production_promotions: 0`

回退前请备份数据库。v0.5.6.4.1 不认识 migration 018；如需回退，应恢复升级前备份，不要手工删除迁移记录。
