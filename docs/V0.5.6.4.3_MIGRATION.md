# CostWeave v0.5.6.4.3 升级说明

v0.5.6.4.3 可直接覆盖 v0.5.6.4.2。首次启动会自动应用 migration 019，将 Runtime Schema 从 `v5.6.4.2` 升级为 `v5.6.4.3`；既有 Run Projection 继续兼容 `v5.5`。

新增数据表：

- `portfolio_audit_reports`
- `portfolio_scenario_comparisons`
- `portfolio_comparison_members`

这些表只保存离线、不可变、带完整性哈希的全局组合审计。数据库检查和触发器固定：

- `advisory_only = true`
- `routing_authority = false`
- `may_change_actual_route = false`
- `commercial_claims_allowed = false`

升级后访问 `GET /api/v1/portfolio/policy`，默认应看到：

- `schema_version: v0.5.6.4.3`
- `solver: bounded-deterministic-beam-search`
- `current_evidence: E0-contract-only`
- `external_calls_required: false`
- `may_change_actual_route: false`
- `portfolio_route_interventions: 0`

升级不会自动读取用户任务、调用外部 Provider、执行 Shadow 路由或改变现有 `ResourcePortfolioOptimizer` 的正式决策。E0 审计结果不能用于商业效果声明。

回退前请备份数据库。旧版不认识 migration 019；如需回退，应恢复升级前备份，不要手工删除迁移记录或新表。
