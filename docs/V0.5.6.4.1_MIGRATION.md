# CostWeave v0.5.6.4.1 升级说明

v0.5.6.4.1 可直接覆盖 v0.5.6.3 程序并继续使用原数据库。首次启动会自动应用 migration 017，将 Runtime Schema 从 `v5.6.3` 升级为 `v5.6.4.1`。既有运行投影继续使用兼容的 `v5.5` 合同，无需重写。

新增表只保存匿名质量摘要、不可变准入决定和冻结预测凭证，不保存原始提示词、Provider 密钥或模型输出正文。旧数据不会被自动视为可训练；只有经现有 Outcome 治理门且达到新准入档位的数据才可能成为离线校准候选。

升级后可读取策略状态：

```text
GET /api/v1/predictors/policy
```

正常默认结果应包含：

- `current_state: frozen`
- `training_enabled_by_default: false`
- `policy_promotion_enabled: false`
- `routing_authority: legacy-resource-optimizer`
- `authoritative_learned_predictions: 0`

回退前请备份数据库。v0.5.6.3 不认识 migration 017；若必须运行旧程序，应恢复升级前备份，不要手工删除迁移记录或新表。
