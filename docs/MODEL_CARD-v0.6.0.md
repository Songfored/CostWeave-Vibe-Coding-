# CostWeave v0.6.0 model/policy card

CostWeave v0.6.0 is a control-plane benchmark and policy orchestration layer, not a language model. Its built-in policies are deterministic baselines: fixed model, deterministic hash-random, static task-family, and recorded decision. They receive a blind case view and cannot inspect observed quality, cost, latency, acceptance, prompts, or predictions before deciding.

The packaged seed uses placeholder `seed-*` model IDs and E0 simulated observations. It does not represent any vendor or model capability.
