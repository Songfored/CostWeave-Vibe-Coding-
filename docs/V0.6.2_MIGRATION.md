# v0.6.2 migration notes

- Active line: `v0.6.2` / runtime schema `v6.2.0` / 32 migrations.
- Migration 032 (`032_capability_evidence_graph.sql`) is append-only and leaves
  migrations 001–031 untouched.
- New tables are project-scoped and immutable: capability nodes, evidence,
  calibration snapshots, route decisions and their idempotency records.
- Existing v0.6.0 contracts and v0.6.1 MetaController tables are preserved.
- The router is advisory-only. No Provider, paid, network, training or
  production policy path is enabled by this migration.

## Upgrade

Starting the runtime against an existing database applies migration 032 after
verifying the checksums of migrations 001–031. A checksum mismatch is a hard
failure; do not edit an applied migration. A fresh installation should report
WAL mode, runtime schema `v6.2.0`, and exactly 32 applied migrations.
