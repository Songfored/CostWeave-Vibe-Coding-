# CostWeave v0.5.6.4.4 升级说明

v0.5.6.4.4 可直接覆盖 v0.5.6.4.3。首次启动会自动应用 migration 020，将 Runtime Schema 从 `v5.6.4.3` 升级为 `v5.6.4.4`；既有 Run Projection 继续兼容 `v5.5`。

新增数据表：

- `portfolio_oracle_results`
- `portfolio_differential_reports`
- `portfolio_sensitivity_reports`

外键要求差分报告绑定已保存的 v0.5.6.4.3 候选审计与同问题 Oracle；敏感性报告必须绑定已保存的精确可行基线。所有表固定：

- `advisory_only = true`
- `routing_authority = false`
- `may_change_actual_route = false`
- `commercial_claims_allowed = false`

升级后访问 `GET /api/v1/portfolio/policy`，应看到：

- 顶层组合审计 Schema：`v0.5.6.4.3`
- `exact_validation.schema_version: v0.5.6.4.4`
- 默认 Oracle 上限：10 个节点、100,000 个候选组合
- `sensitivity_claim_scope: tested-points-only`
- `portfolio_validation_route_interventions: 0`

升级不会自动扫描已有任务、运行 Oracle、调用 Provider、替换正式路线或执行敏感性分析。用户必须显式提供组合问题和探针；E0 结果不能用于真实效果声明。

旧版不认识 migration 020。回退时应恢复升级前数据库备份，不要手工删除迁移记录或新表。
