# CostWeave v0.5.8.4 安全报告

## 范围

本报告覆盖单机回环 HTTP 服务、SQLite 控制内核、实验 Adapter、安全边界、发布验证 CLI 和发布资产。它不是公网多租户部署认证，也不是渗透测试证明。

## 已实施控制

- 服务只允许绑定回环地址；
- 外部与付费 Adapter 双开关默认关闭；
- Adapter 插件/修订/能力白名单，未知项在网络前拒绝；
- 远程仅 HTTPS，拒绝 URL 凭据、重定向、私网/保留地址和超限响应；
- 密钥短时租约、值零持久化、结构化与文本双层脱敏；
- 项目范围、跨项目 not-found 语义和不可变逻辑撤销墓碑；
- Prompt 不可信字段与工具权限、禁止动作和输出 Schema 分离；
- Provider 幂等副作用合同，歧义结果不自动重放；
- EventLog、投影、stream revision 和备份逻辑根完整性；
- release attestation、恢复、策略和证据收据追加写且不可修改/删除。

## 安全验证

自动化覆盖 SSRF、Prompt/工具越权、密钥脱敏、项目隔离、幂等冲突、事件篡改、清单篡改、恢复失败关闭和不可变触发器。完整计数与执行结果见 `ACCEPTANCE-v0.5.8.4.md`。

## 剩余风险

- 没有公网身份认证、租户身份系统或速率限制网关；
- 没有 OS 级沙箱、容器隔离、HSM 或加密密钥销毁；
- 项目删除是逻辑撤销，不是物理擦除证明；
- 本地数据库访问者仍可能读取未加密业务元数据；
- 真实 Provider SDK、流式响应、账单和供应链兼容性未验证；
- 单进程 SQLite 不提供分布式容错或节点级隔离。

## 部署要求

不要把 v0.5 直接暴露到公网。若进入 v0.6 生产化，应先增加身份认证、反向代理限流、进程/容器隔离、密钥管理、审计集中化、依赖扫描和真实 Adapter 安全测试。
