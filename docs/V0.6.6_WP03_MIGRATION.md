# v0.6.6 V066-WP03 migration and rollback

No database migration is required. Runtime schema remains v6.5.0 with 35
migrations. Import the new classes from `costweave.gateway_litellm` or
`costweave.adapters`.

```python
from costweave.adapters import (
    FakeLiteLLMServer,
    LiteLLMGatewayBackend,
    LiteLLMGatewayConfig,
    LiteLLMRuntimePolicy,
)

backend = LiteLLMGatewayBackend(
    LiteLLMGatewayConfig(
        backend_id="litellm-gateway",
        model_aliases={"planner": "openai/gpt-4o-mini"},
    ),
    policy=LiteLLMRuntimePolicy(gateway_enabled=True),
    transport=FakeLiteLLMServer(),
)
```

The example uses the in-process fixture. A real gateway must be supplied by
the caller and separately authorized; CostWeave does not load its SDK or
credentials. The default constructor remains disabled.

## Rollback

Remove the WP03 imports and reinstall the previous v0.6.6 WP02 artifact. No
database restore or migration reversal is needed because WP03 adds no durable
tables or events.
