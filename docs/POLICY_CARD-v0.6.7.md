# CostWeave v0.6.7 策略卡

- 网络调用、Provider 调用和付费调用：默认关闭；
- Prompt 与 Provider 输出：默认不进入外部遥测；
- 本地 API：要求回环 Host 和高熵会话令牌；
- 项目头：仅是认证后的本地选择器，不是凭据；
- 风险 Prompt：要求权威且意图绑定的审批；
- 外部 transport：要求一次性、请求绑定 capability；
- 模糊账单：保守冻结最坏成本，不按 0 结算；
- 全局副作用 replay：不得再次执行 transport；
- 秘密输出：在解析和持久化前拒绝；
- 项目撤销和驻留域：运行、事件、证据、导出收据、账本、审批与小预算 Shadow 的读取和动作均按完整作用域授权；
- 生产就绪：始终为 `false`；
- 当前修复通过本地矩阵与回归，但修复后独立复扫通过前不得宣传为安全正式版。
