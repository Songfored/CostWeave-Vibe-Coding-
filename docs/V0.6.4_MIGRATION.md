# v0.6.4 migration notes

- Active line: `v0.6.4` / runtime schema `v6.4.0` / 34 migrations.
- Migration 034 (`034_execution_time_belief_economic_recovery.sql`) adds
  immutable progress-belief, recovery-decision and idempotency tables.
- Existing v0.6.3 joint-search records remain readable and immutable.
- The stable execution route is unchanged; v0.6.4 only exposes an advisory
  control-plane service.

## API

Use `confirm=RUN_EXECUTION_RECOVERY` and an `Idempotency-Key` header:

- `GET /api/v1/execution-recovery/status`
- `POST /api/v1/execution-recovery/decide`
- `GET /api/v1/execution-recovery/{decision_id}`

The request contains a complete `v0.6.4` `snapshot`. The response includes the
updated belief, all seven options, hard checks, baseline CPS and the selected
advisory action.

## Rollback

Take a verified runtime backup before upgrading. Downgrading the application
does not remove migration 034; restore the backup and deploy the prior
application if the new line must be removed. Never edit or delete v0.6.4
records in place.
