# CostWeave v0.5.7.2

发布日期：2026-08-04  
主题：Production-like Shadow

## 新增

- 基线任务特征、目录、容量和实际路线的同源冻结输入。
- 五种旁路策略与容量新鲜度、硬约束、预算、时限门。
- 受限缺失原因、异常隔离回执和基线连续执行保证。
- 建议质量、成本、时延、容量预测及实际基线误差比较。
- 覆盖率、比较覆盖率、缺失原因、P50/P95 延迟与开销审计。
- 端到端成本 10% P95 原则门和至少 30 个 E2+ 完整案例门。
- migration 023、不可变证据链、互斥决定/失败与公开 Shadow API。

## 安全边界

- 默认外部 Provider 调用：0。
- 实际路线变化：0。
- 执行副作用：0。
- Shadow 失败影响基线：0。
- 自动生产晋级：0。
- 测试夹具商业声明资格：关闭。

## 验证

- 新增 26 项专项与 API 测试。
- 自动化测试基线：621 项。
- 30 例测试验证完整比较与 10% 开销门，但属于 E0 工程夹具，不是现实 Shadow 数据。
