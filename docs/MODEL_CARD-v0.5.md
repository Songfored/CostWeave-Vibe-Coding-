# CostWeave v0.5 模型卡

## 系统身份

CostWeave 不是一个训练完成的大语言模型，也不随包分发任何模型权重。它是跨 Provider、多模型和本地资源的离线控制平面原型。模型目录保存可编辑事实、价格和能力先验；默认执行器是确定性模拟器。

## 预期用途

- 把复杂目标拆成 DAG，并识别可以并行的节点；
- 在 Planner / MultiPlanner 间作两层管理决策；
- 按能力、风险、成本、时延、容量和返工损失选择候选资源；
- 生成结构化 WorkOrder、验收合同、恢复与审计记录；
- 在接入真实模型前离线验证路由和治理机制。

## 非预期用途

- 代替安全、医疗、法律或财务专家作最终高风险决定；
- 在没有真实证据时自动推广策略或宣传固定降本；
- 直接暴露为公网多租户服务；
- 把模型自报置信度当作正确率；
- 未经批准执行不可逆、付费或外部副作用操作。

## 能力来源

当前任务理解、难度评分、规划和路由来自可审计规则、损失函数、版本化目录与仿真先验，不来自 v0.5 内训练的新模型。目录中的推理、速度、可靠性和价格必须由导入者维护来源与核验时间。

## 已验证

- 结构化合同、DAG、两层管理上限和并行调度语义；
- 预测/实际/模拟/缺失证据分离；
- 默认零真实和零付费模型调用；
- EventLog、投影、备份、恢复和失败关闭机制；
- 模型目录 JSON/CSV 原子导入、编辑、导出和 revision 冲突。

## 未验证

- 对任意真实任务的最终答案质量；
- 不同真实模型组合相对单一强模型的收益；
- 国内外模型实时价格、容量与故障表现；
- 真实提示词交接对返工率的改善；
- 生产流量下的自学习效果。

## 人工监督

Auth、权限、数据库迁移、安全、隐私、公共 API、核心业务和不可逆动作必须回到高权限决策层并保留人工批准。推理强度不等于权限等级。
