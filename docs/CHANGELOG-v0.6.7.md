# CostWeave v0.6.7 — Security Foundation Recovery

## 新增

- `RequestSecurityContextV1`：保存认证主体、项目、活动状态、驻留域、操作范围、审批范围和请求身份；
- `ExternalCallAuthorityV1`：集中执行调用准入、预算与副作用预留、一次性 capability、秘密输出检查和终态关闭；
- 本地 Web 会话令牌：高熵生成、URL fragment 交付、会话存储和所有 API 自动附加；
- 固定 DNS 地址的 HTTPS transport，TLS SNI 仍使用原始主机名并校验实际 peer；
- HTTP 活跃请求上限、过载计数和恢复指标；
- 13 项 v0.6.7 攻击路径回归和 4 项跨入口驻留区矩阵回归；
- 发布门禁中的 `security-foundation-contract-self-test`。

## 修改

- 所有 HTTP 方法在路由前统一检查 Host、Origin、站点来源和会话身份；
- 静态资源解析拒绝盘符、UNC、反斜杠、NUL、`..` 和解析后目录逃逸；
- 项目撤销在 API 分发前集中生效；运行、媒体、事件、证据控制台/导出、导出收据、账本、审批与小预算 Shadow 使用项目和驻留域完整作用域；
- 隔离回归运行器固定子进程 UTF-8 输出，并在 Windows 非 UTF-8 控制台安全呈现失败诊断；
- 风险 Prompt 必须命中真实、已批准且与项目、运行、任务、意图和风险绑定的审批记录；
- Provider 输出在解析、哈希、日志或持久化前检查活跃秘密及受控编码形式；
- 429、503、超时及 transport 后异常按可能已计费处理，保守保留最坏成本；
- 项目级全局副作用 replay 命中时复用已完成结果，不再次调用 transport；
- 发布版本统一为 v0.6.7，发布门禁从 18 项增至 19 项。
- 重试成本改为“每次重试前原子扩充预留、按全部实际尝试结算”，预算不足时不再启动下一次尝试；
- 调度准入、工件/成本/金丝雀/媒体/runtime 写入与项目撤销使用统一活动项目边界；
- 运行请求身份不可变，查询、列表和动作入口校验持久化项目与驻留区归属；
- DNS 与小预算 Shadow 使用有界、可终止的进程隔离；独立测试运行器把后台线程异常计为失败；
- 最新验收为全量 1058/1058、隔离 1058/1058、严格资源检查 54/54、发布门禁 19/19；
- 修复后标准扫描 `6897135e-a85a-4c65-9088-d62a3ae6f573` 覆盖 12/12 威胁面，0 项可报告发现。

## 未包含

- 真实 Provider 或付费调用；
- 公网部署、多用户认证、租户 ACL 或跨进程分布式锁；
- 新路由算法、模型能力提升或在线学习；
- 最新发布包重建与干净安装。修复后源码安全复扫已经成功关闭，但旧 wheel、sdist 与哈希已经失效，详见验收报告。
