# CostWeave v0.6.7 数据卡

## 处理的数据

本地控制面可处理用户任务、项目 ID、驻留域、审批元数据、请求哈希、模型目录、运行状态、预算和结果。高熵会话令牌只保存在进程内和浏览器当前标签页会话存储；transport capability 只存在于进程内，不持久化秘密值。

## 安全处理

- 活跃秘密及受控编码形式在 Provider 响应持久化前检查；
- 会话认证发生在 API 路由和项目选择之前；
- 项目撤销和驻留域参与运行、事件、证据、导出收据、账本、审批与小预算 Shadow 的资源读取和动作；
- 日志与错误只保存固定安全错误码和摘要；
- 外部调用默认关闭，本次验收真实外部调用为 0。

## 证据数据

v0.6.7 仅使用模拟 Provider、固定 DNS/peer、SQLite 临时库和确定性攻击夹具。没有采集真实用户 Prompt、真实 Provider 输出、真实账单或训练数据，也没有让安全回归结果自动更新路由策略。

## 限制

当前证据为 E0，不能代表生产隐私、合规或多租户隔离。独立标准复扫已发现并促成本次派生读取驻留区修复，但修复后复扫尚未执行，相关发现不能标记为最终关闭。
