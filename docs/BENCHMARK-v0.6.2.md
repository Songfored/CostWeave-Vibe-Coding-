# v0.6.2 benchmark card

This release contains contract and deterministic fixture tests only. The demo
evidence is `E0-simulated`; it must not be interpreted as a real benchmark.

The release comparison surface is the structured route decision:

- candidate set and all assessments;
- conservative success lower bound and coverage;
- calibration status and reason codes;
- evidence IDs and trace hash;
- provider, network and commercial-claim counters.

No quality, cost or latency superiority claim is admitted until a preregistered
real-data tournament supplies task-, project- and time-isolated observations.
