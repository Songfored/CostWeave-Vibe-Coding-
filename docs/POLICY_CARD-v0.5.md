# CostWeave v0.5 策略卡

## 策略目标

在质量、成本、时间、风险和返工之间最小化端到端预期损失，而不是单纯选择最便宜或最强模型。

## 决策层级

1. MetaPlanner 判断不委派、单 Planner 或 MultiPlanner。
2. MultiPlanner 最多使用一层匿名提案与一层独立裁决。
3. DAG Scheduler 只执行边界明确的节点；管理嵌套深度固定为两层。

## 主要输入

- 六维任务难度、不确定性、错误成本和上下文需求；
- 模型能力、价格、时延、可靠性与资料可信度先验；
- 预算、deadline、容量、并发和副作用权限；
- 历史 Outcome、失败分类、校准和证据等级。

## 硬门

- 高风险、越权、预算不足、上下文不足和 OOD 任务不得乐观放行；
- 本地容量不足应在首次执行前拒绝或升级；
- 歧义外部副作用不自动重放；
- 终态任务不重启，已验收且未污染成果不重复执行；
- 没有 E2+ 真实证据时，学习、推广、Canary 和商业结论保持冻结。

## 默认状态

- 外部 Adapter：关闭；
- 付费调用：关闭；
- Canary：关闭；
- 自动策略晋级：关闭；
- 高风险探索：0；
- 真实商业结论：不允许。

## 失败与回滚

策略必须记录候选、淘汰理由、版本、门槛和回滚目标。失败数据不会被成功样本覆盖；污染范围、恢复次数、预算和时间均有界。策略注册表中的 `active` 不等于生产流量已经激活。

## 当前限制

路由策略尚未由真实流量校准；ExpectedLoss、Psuccess、Pcomplete、成本和时延是工程先验与仿真输出。世界领先、固定降本和真实提速均未验证。
