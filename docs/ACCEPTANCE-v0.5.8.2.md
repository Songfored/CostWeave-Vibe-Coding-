# CostWeave v0.5.8.2 验收报告

验收日期：2026-08-05

## 结论

v0.5.8.2 的工程合同满足发布条件：中央安全边界已接入实验 HTTP Adapter 和公开数据出口；项目、密钥、网络、Prompt/工具与副作用的失败关闭路径均有自动化证据。默认安装不会访问真实网络或产生付费调用。

## 硬门结果

| 硬门 | 结果 | 证据 |
|---|---|---|
| 密钥公开或持久化泄漏 | 0 | 结构化/文本脱敏、SecretLease、配置/回执扫描测试 |
| 未授权网络或工具调用 | 0 | 双开关、插件/端点/Prompt/工具准入均在 transport 前 |
| 跨项目 Run / Artifact / Export 泄漏 | 0 | API 使用不同项目头返回 404 或空集合 |
| 外部副作用无幂等/补偿 | 0 | 网络前不可变合同、Provider 幂等键、同键冲突拒绝 |
| 歧义副作用自动重放 | 0 | transport ambiguity 写入 `ambiguous` 并停止 |
| 默认真实/付费调用 | 0 | 两个环境开关默认均关闭 |

## 自动化范围

- 完整基线：679 项；新增安全专项/API 测试：8 项。
- migration 027、Runtime Schema `v5.8.2`、旧投影默认值和默认项目幂等兼容已覆盖。
- 页面结构、响应式规则和安全状态加载纳入既有 UI 回归。

## 诚实边界

- “零泄漏”结论只覆盖仓库实现、自动化语料和本机 HTTP/SQLite 出口，不是形式化证明，也不覆盖操作系统、第三方 Provider 或宿主机恶意软件。
- DNS 公网地址检查发生在连接前；标准库传输未固定已解析 IP，不能替代独立网络代理对 DNS TOCTOU/重绑定风险的系统级防护。
- 项目撤销是逻辑访问撤销，不是物理行擦除；历史备份、磁盘残留和加密擦除未实现。
- Adapter 仍属默认关闭的实验接口；没有真实 Provider 兼容性或生产负载证据。
- 679 项测试证明控制机制，不证明 CostWeave 已实现真实质量提升、固定降本比例或生产级多租户安全。
