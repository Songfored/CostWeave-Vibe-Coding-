# CostWeave v0.6.9 数据卡

## 使用的数据

v0.6.9 只使用运行时已有的 E0 数据：用户任务合同、原路由候选、可编辑模型目录、静态价格字段、本地容量占位、模拟成功/成本/时延分布，以及明确标记为 `E0-simulated` 的安全学习观察。

## 数据血缘

- Run、Trace、任务合同、验收标准和 baseline 路由来自同一运行投影；
- 目录、价格和 worker 容量来自该 Run 启动时冻结的模型快照；
- ExecutionRecovery 的首节点 `suspect` 是只存在于影子 Payload 的 E0 预执行不确定性夹具，不会写入正式 DAG；
- SafeLearning 的 12 条观察是测试夹具，`independently_validated=false`，不可用于自动晋级。

## 可支持结论

可证明五个模块能共享同一输入并生成可持久化轨迹，影子链影响为 0，失败能关闭到 baseline。

## 不可支持结论

不能据此证明真实模型质量、成本节省比例、生产容量、供应商可靠性、长期学习收益或世界领先水平。
