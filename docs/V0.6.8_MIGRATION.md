# 升级到 CostWeave v0.6.8

v0.6.8 是交付层升级，不新增数据库迁移。Runtime Schema 保持 `v6.5.0`，迁移数保持 35。

## 兼容变化

- `/api/health.version` 从历史兼容值改为唯一当前应用版本 `0.6.8`；
- 删除重复的 `development_version` 字段；
- `version_line.stable_baseline` 继续明确保存历史工程基线，`active_development` 指向 `v0.6.8`；
- 包元数据改为从 `costweave.version.__version__` 动态读取；
- HTTP User-Agent 和服务标识跟随统一版本源。

依赖旧健康字段的客户端应改读 `version`。不得把外部调用安全合同的 `v0.6.7` Schema 当作应用版本并批量替换。

## 回滚

回滚应用代码不要求回滚数据库。保留 v0.6.7 构建物和校验值，在独立目录安装即可。不要删除现有运行数据库，不要重写已经应用的迁移。
