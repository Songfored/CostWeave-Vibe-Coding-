# CostWeave v0.5.8.1

## 新增

- Unified Evidence Console：统一展示全局或单运行的规划、Planner、路由、Placement、成本、容量、Outcome、评测、Shadow、策略和 Canary 证据；
- 四类互斥证据语义：实际控制面记录、预测值、模拟值和缺失值；
- E0～E5 等级、来源 API、数据版本、记录数、新鲜度与确定性来源哈希；
- 真实质量、真实 CPS 和真实 P95 三类商业结论门；
- 有界脱敏实验包、规范化 SHA-256 完整性校验和幂等导出；
- migration 026：不可修改、不可删除的实验包导出收据；
- 全局/单运行证据 API、导出收据 API 和响应式页面控制台。

## 数据诚实性

- 实际控制面计数不自动升级为真实效果证据；
- 未独立验收的真实成功率、未完成账单对账的 CPS 和样本不足的 P95 固定显示为缺失；
- 模拟评测案例和模拟账本不会进入商业结论；
- 导出不包含密钥、Prompt 原文或 Artifact 内容；
- 当前可声明商业效果结论为 0。

## 验证

- 671 项自动化测试通过，0 失败；
- v0.5.8.1 新增 13 项专项证据/导出测试和 1 项公开 API 测试；
- 桌面、平板和手机浏览器检查无横向溢出；筛选和实验包导出正常；
- 页面应用控制台错误与警告为 0。

## 证据边界

本版证明统一证据合同、追溯、缺失语义和导出机制可运行，不证明 CostWeave 已真实降低成本、提高成功率或缩短端到端时延。真实效果样本、置信区间和可声明商业结论仍为 0。
