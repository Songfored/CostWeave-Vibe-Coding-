## 安全不变量

1. 活动凭据原文及受控组合编码不能进入输出、收据、日志、Trace 或 SQLite；
2. 外部 transport 只能消费一次与项目、驻留区、端点、请求和副作用合同绑定的能力；
3. 项目 tombstone 与受保护写入有明确顺序，撤销后不能产生新的项目派生状态；
4. 项目与数据驻留区必须同时匹配，内存归属与持久化归属冲突时失败关闭；
5. 重试只能在预算已原子预留后发生，所有已发生尝试都进入成本结算；
6. DNS、Shadow、HTTP 请求和后台进程必须受绝对截止时间与并发上限约束；
7. 外部与付费调用默认关闭，发布门禁持续验证该默认值。

## 仍然存在的边界

- 当前安全模型是回环地址、单用户、单进程，不是公网身份系统或多租户隔离证明；
- authority 和预算账本仍是进程内协调多个 SQLite 存储，不是跨节点分布式事务；
- 没有真实供应商、代理、企业证书、恶意流式响应、真实账单延迟或生产网络证据；
- 同进程任意内存写、数据库直写和操作系统账户失陷不属于当前安全边界；
- 历史 wheel、sdist 和哈希不对应最新源码，必须重建后才能发布。
