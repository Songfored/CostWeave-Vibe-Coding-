# CostWeave v0.5.6.4.2

## 新增

- 冻结预测器制品合同：绑定准入报告、数据哈希、方法、特征/目标 Schema、代码版本、训练配置和模型载荷哈希。
- 五类 Outcome 观察合同：首次成功、修复成功、升级成功、人工介入成功和最终失败。
- 离线指标：成功率与 95% 区间、Brier、ECE、高风险 ECE、高风险误放行、难度排序 Spearman、成本/时延 P95 覆盖率、CPS 和 Time per Accepted Task。
- 离线门：匿名标识、test-only、样本唯一、数据版本一致、E2+ 证据、有效样本数和高风险样本数。
- Champion/Challenger：相同 Cohort、成功率非劣、校准与高风险非退化、成本或时延价值门。
- migration 018：冻结制品、离线报告和挑战者比较的不可变持久化与完整性校验。
- Predictor Policy API 同时公开 v0.5.6.4.1 准入门和 v0.5.6.4.2 离线验收门。

## 硬边界

- E0/E1 指标不能通过离线验收。
- E2 不能进入 Shadow。
- E3+ 通过也只能成为 Shadow 候选。
- 离线评估、挑战者比较和持久化记录均不能授予正式路由权或策略晋级权。
- 当前真实调用、真实训练、Shadow 执行和生产晋级均为 0。
