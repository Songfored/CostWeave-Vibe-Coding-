# CostWeave v0.5 数据卡

## 数据资产

| 数据 | 当前内容 | 证据等级 | 用途 |
|---|---|---|---|
| 固定种子任务 | 35 个版本化合成任务 | E0 | 评测协议完整性 |
| 模型目录 | 内置基线及用户导入记录 | 先验 | 路由输入，不是官方榜单 |
| 模拟运行 | 本地执行器产生的任务、事件、成本和验收 | E0 | 控制平面回归 |
| 离线回放 | 冻结版本与已知 Outcome | E1 | 路由差分与 regret 合同 |
| 韧性夹具 | 故障、并发、deadline、恢复案例 | E0 | 故障合同验收 |
| 真实效果数据 | 0 个达到门槛的案例 | missing | 不得支持商业结论 |

## 数据治理

- 项目、任务族、时间和 train/calibration/test 分区必须隔离；
- 同一项目不得同时进入训练和测试；
- 标签必须保留来源、冲突、删除墓碑与审计；
- Prompt 原文、密钥、用户标识和 Artifact 内容默认不进入证据导出；
- 低证据、重复、过期和未知反事实样本不能推动策略晋级。

## 隐私与保留

默认本地运行，不上传数据。项目撤销目前是立即生效的逻辑访问撤销，不是可证明的物理擦除。v0.5 不提供公网身份认证、加密密钥销毁或法规级删除证明。

## 偏差与代表性

固定任务集规模小、合成且由工程规则构造，不能代表真实行业、语言、用户群或 Provider 分布。当前真实效果样本为 0，所以任何真实质量、成本和时延估计都应显示为缺失，而不是补零。

## 学习准入

只有来源清楚、项目隔离、标签完整、样本量达标并通过校准/测试门的数据才能成为候选训练资产。当前 v0.5 默认训练与策略晋级冻结。
