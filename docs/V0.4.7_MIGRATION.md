# CostWeave v0.4.7 迁移指南

v0.4.7 在 v0.4.6 数据库上追加迁移 006，不删除或重写既有运行、事件、Artifact、Placement、验收或恢复记录。

## 升级

1. 停止旧进程并备份 `~/.costweave/runtime-v4.sqlite3`。
2. 安装或解压 v0.4.7。
3. 启动服务；迁移自动创建预测、Outcome、校准器、能力后验和评估表。
4. 访问 `/api/health`，确认：
   - `version` 为 `0.4.7`
   - `control_kernel.runtime_schema` 为 `v4.7`
   - `control_kernel.migrations` 为 `6`
   - `features.outcome_forecast` 为 `true`

旧 v4.2～v4.6 投影继续兼容读取。旧运行没有执行前预测时，预测接口返回不可用，而不是用执行后信息伪造预测。

## 回滚预测写入

```powershell
$env:COSTWEAVE_OUTCOME_FORECAST="0"
python -m costweave.server
```

关闭后核心规划、路由、执行、验收和恢复继续运行；不生成新的预测、Outcome 或后验更新。已持久化预测和评估仍可查询。

## 数据解释

- `forecast_snapshots` 是执行前冻结的预测，不随结果回写。
- `outcomes` 每个运行至多一条，重复终态处理不会重复学习。
- `capability_posteriors` 使用 Beta 成功/失败统计，并按四级范围聚合。
- `forecast_calibrators` 保存校准参数和样本量，可审计、可回滚。
- `evaluation_runs` 保存冻结基准结果，不应与真实生产 A/B 测试混为一谈。
