# CostWeave v0.5.4 升级说明

v0.5.4 可直接覆盖 v0.5.3 程序文件，并继续使用原运行数据库。首次启动会自动应用 migration 012，将 Runtime / Projection Schema 升级为 `v5.4`。

## 数据库变化

- `placements.decision_json`：保存部署键、后验摘要、预执行准入结果与时延预测。
- 新增能力后验和 Placement 查询索引。
- 旧 `v5.3`、`v5.2`、`v5.1` 与 `v4.9` 投影仍可读取。

## 行为变化

- 路由单位从单一模型扩展为模型、Provider、Endpoint、推理档位和任务族的组合。
- 低价候选预计造成更高返工成本时，可在首次执行前被更强候选替代。
- 本地容量、显存、队列、Bulkhead、熔断和期限 P95 会参与预执行准入。
- 新增 `quality` 质量优先模式；原 `economy`、`balanced`、`turbo` 保持兼容。
- 理想组合超预算时先沿质量/成本/时延前沿寻找可行组合，并保持独立验收与期限约束；无可行组合时仍执行硬拒绝。
- 新增 `GET /api/v1/runs/{id}/economics`。

## 回退

回退前先备份运行数据库。v0.5.3 不认识 `v5.4` 投影和 migration 012 新字段，建议保留 v0.5.4 程序读取已升级数据库。模型目录格式无需降级。
