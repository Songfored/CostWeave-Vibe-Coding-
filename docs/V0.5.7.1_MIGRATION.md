# CostWeave v0.5.7.1 升级说明

v0.5.7.1 可直接覆盖 v0.5.6.5。首次启动自动应用 migration 022，将 Runtime Schema 从 `v5.6.5` 升级为 `v5.7.1`；旧运行、预测器、Portfolio 和策略候选记录保持不变。

## 新增数据表

- `replay_version_snapshots`：冻结策略、特征、合同、目录、Prompt、工具、容量、目标、约束和代码版本。
- `offline_replay_cases`：匿名任务、风险、候选、硬约束和历史实选路线。
- `observed_route_outcomes`：真实或夹具路线结果、证据等级、来源、独立验收和 propensity。
- `offline_replay_results`：每个案例与冻结策略版本的确定性决定。
- `approximate_oracle_reports`：已观测最佳路线、未知路线、覆盖率和方向性证据资格。
- `replay_benchmark_reports`：多基线 Regret、median/P90、数据偏差和证据门。

## 行为变化

- 新增 `GET /api/v1/replay/policy`。
- 健康状态新增 `offline_replay` 合同和回放证据计数。
- 默认安装不会调用外部模型、执行多路线、改变实际路由或晋级策略。
- 未观测路线保持 `unknown`；近似 Oracle 不证明全局最优。

## 兼容与回滚

- 正式路由继续由 `legacy-resource-optimizer` 掌握。
- 所有 v0.5.7.1 记录不可修改或删除，路由权、外部调用、生产晋级和商业声明字段由数据库固定为零。
- 回退代码前请保留数据库备份；旧程序会忽略 migration 022 新表，既有表格式未被改写。

## 证据边界

升级不自动产生历史多路线结果，也不会把旧 Outcome 推断成反事实。median `≤ 8%` 与 P90 `≤ 20%` 只有在至少 30 个 E2+ 真实、独立、完整案例满足全部偏差门时才可评估；当前仓库尚无这类真实证据。
