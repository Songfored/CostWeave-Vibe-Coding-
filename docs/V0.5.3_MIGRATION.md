# CostWeave v0.5.3 升级说明

v0.5.3 可以直接覆盖 v0.5.2 程序文件并继续使用原运行数据库。首次启动自动应用 migration 011，并把 Runtime / Projection Schema 升级为 `v5.3`。

## 数据兼容

- v5.2 及更早的受支持投影仍可读取；旧记录的 `planning.deliberation` 为 `null`。
- 新运行会在 `planning` 下保存 `decision`、原始 `proposals` 与身份隔离的 `deliberation` 回执。
- migration 011 只增加事件审计索引，不复制规划事实，也不修改模型目录。

## 新增回执

`planning.deliberation` 包含：

- 匿名提案 A/B/C；
- 六维约束评分和硬约束结果；
- 冲突类型、严重度与证据；
- 一轮以内的选中、合并、淘汰解释；
- 实际调用数、规划成本、并行时延、预算降级和稳定指纹。

## 不变的安全边界

- 管理深度固定为两层；
- 单轮最多三个 Planner；
- 最多一轮裁决；
- 不使用多数投票替代证据；
- 默认不启用任何付费 Provider；
- API Key 不进入模型目录或规划回执。

## 回退

回退程序前应先备份运行数据库。v0.5.2 不认识 v5.3 投影，建议保留 v0.5.3 程序读取新记录；模型目录不需要降级。
